## 环境恢复原则

1. 优先保留可工作的G盘现有环境。新机安装先读各源码的pyproject和INSTALL；Windows与开发机的CUDA wheel不同，不能直接用远端requirements.lock替代本机。
2. 在新机建立独立环境，再安装本仓库匹配版本的源码；根据实际路径改环境脚本，不能覆盖其他项目。
3. 当前机械臂的校准/COM备份只在确认同一设备时恢复。其他机械臂要重新按官方流程校准。
4. Hugging Face重新登录走工具正常凭据存储；GitHub/SSH/HF密钥从用户授权环境获取，禁止写进项目配置。
5. 读取或部署checkpoint时，从开发机取完整pretrained_model；GitHub中的JSON副本只有说明用途。
